# Patent–paper pairs

Patent citations come from the [Reliance on Science](https://relianceonscience.org/patent-paper-pairs) patent–paper pairs (USPTO patents up to 2021, linked to OpenAlex works). Each pair has a confidence score and the number of days between the publication of the paper and the filing of the patent.

The dataset is not included in this repository. Download it and save it as `_patent_paper_pairs.csv` in this folder; it is loaded by [`3_add_patents_to_dwh.py`](../../3_dwh/1_build/3_add_patents_to_dwh.py).
